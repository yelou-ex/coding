## 〇、符号与代数设定

### 0.1 环

| 记号 | 含义 |
|---|---|
| `R_t = Z_t[X]/(X^N+1)` | 明文环 |
| `R_q = Z_q[X]/(X^N+1)` | 密文环 |
| `N` | 环维度（2 的幂） |
| `X^N = -1` | **负循环**（negacyclic），全程的符号来源 |

### 0.2 槽位

要求 `X^N+1` 在 `F_t` 上**完全分裂**，设其 `N` 个根为 `ζ_0..ζ_{N-1}`。则

```
BatchEncoder :  Z_t^N  →  R_t
                 v      ↦  v̂(X) = Σ_s v_s · L_s(X)
```

其中 `L_s` 是拉格朗日基：`L_s(ζ_r) = δ_{sr}`（Kronecker delta）。

于是 **逐点相乘 = 逐槽相乘**：

```
\widehat{(v ⊙ w)} = v̂ · ŵ          （槽位域乘法 = 环乘法）
```

> ⚠️ 反之，在系数域做 `CtCtMul` 得到的是**卷积** `a ⊛ b`，
> `Σ_k (a⊛b)_k = (Σ a)(Σ b) = |a||b|` —— 与内积无关。**二进制内积只能在槽位域做。**

### 0.3 三种"域"与其转换

| 域 | 数据形态 | 用途 |
|---|---|---|
| **系数域** | 多项式系数直接是数据 | 数据库 `P_{c,b}(X)`、BFF 编码 |
| **槽位域** | 求值表示 `v(ζ_s)` | Bloom 内积、Pack 输出 |
| **NTT 域** | `q` 上的快速求值 | 仅实现层用，语义同系数域 |

转换算子：`toSlots(·) = (·)(ζ_·)`，`toCoeff(·) = Σ(·)_s L_s`。

### 0.4 缩放（BFV）

`Δ = ⌊q/t⌋`。密文相位为 `Δ·m + e`（`e` 为噪声）。

```
编码 :  m ↦ Δ·m
解码 :  c ↦ round(c/Δ)  mod t
```

**可表达上界**：`|m| ≤ ⌊(q/2)/Δ⌋`。超出会翻到负半轴，解码错误。

### 0.5 密钥（一套秘密，两种形态）

```
s_L = (s_L[0], …, s_L[d−1]) ∈ {0,1}^d                    LWE 私钥
s_R(X) = Σ_{j<d} s_L[j]·X^j  ∈ R_q                        RLWE 私钥（同源）
```

**"同源"是整条链能闭合的关键**：`s_R` 的第 `j` 个系数就是 `s_L[j]`。
所以 SampleExtract 后落回 `s_L`，Pack 又把它送回 `s_R`，全程只有一套秘密。

### 0.6 密文类型

| 类型 | 形态 | 相位 |
|---|---|---|
| **RLWE** | `ct = (c_0, c_1) ∈ R_q²` | `φ(ct) = c_0 + c_1·s_R` |
| **RGSW** | `(G_0, G_1)`,各 `ℓ` 条 RLWE | `φ(G^{(0)}_i) = B^i·μ`，`φ(G^{(1)}_i) = B^i·μ·s_R` |
| **LWE** | `(a, b)` | `φ = b − ⟨a, s_L⟩` |

### 0.7 五个基本算子（实现层必须能调）

| 算子 | 语义 | 相位变化 |
|---|---|---|
| `CtAdd(ct, ct')` | 密文相加 | `φ + φ'` |
| `CtPtMul(ct, m)` | 密文 × **明文**多项式（或二进制内积的单元） | `m · φ` |
| `CtRotate(ct, k)` | 乘 `X^k`（公开） | `X^k · φ` |
| `CtExtract_j(ct)` | 取**第 j 个系数** → LWE（SampleExtract，密钥变成循环移位） | 见 §2.2.2 |
| `CtCtMul(ct, ct')` | 密文 × 密文 + 重线性化 | 见 §3.7 |
| `CtExtract_0(ct)` | 取常数项 → LWE | 见 §3.4 |

## 一、SETUP（服务器侧，**全部明文**）

> **关键前提：CAPE 是 PIR，不是 FHE 数据库。数据库是服务器的资产，不加密。**
> 只有**查询**是加密的。全程 SETUP 不出现任何 `Enc`。

### 1.1 关键字与值的关系

```
数据库： K_i ↦ V_{K_i} = { v_{i,1}, …, v_{i,m_i} }     （关键字 K_i 关联的值集合）
反向：   S_v = { K_i : v ∈ V_{K_i} }                   （值 v 被哪些关键字关联）
```

### 1.2 Bloom 过滤器

对每个出现过的值 `v`：

```
b_v = BF.Gen(S_v) ∈ {0,1}^{ℓ_BF}
```

**决定性要求**：位位置只依赖关键字本身，与值无关。即存在哈希函数族
`h_0..h_{κ−1} : Key → [ℓ_BF]` 使得

```
b_v[i] = 1  ⟺  存在 K ∈ S_v 使 h_j(K) = i（某个 j）
```

> ⚠️ **若位位置写成了 `h(K ‖ v)`，则客户端与服务端的位永远对不上，内积恒为 0。**

### 1.3 payload 展平

每个关键字 `K_i` 的 payload 是一个 `B_pay` 维向量：

```
payload_i = [ fp(K_i) │ m_i │ v_{i,1} │ b_{v_{i,1}} │ … │ v_{i,m_i} │ b_{v_{i,m_i}} ]
              └─指纹─┘  └个数┘  └值─┘  └─Bloom──┘     └值─┘    └─Bloom──┘
```

**字段索引约定（必须全局统一）**：

```
字段 0 … β_fp−1                   : 指纹（拆成 β_fp 个 limb）
字段 β_fp … β_fp+1                : 值的个数 m_i（拆成 2 个 limb）
字段 β_fp + 2 + (j−1)(1+ℓ_BF) + 0 : 第 j 个值 v_{i,j}
字段 β_fp + 2 + (j−1)(1+ℓ_BF) + 1 + i : 该值的 Bloom 第 i 位
```

于是

```
B_pay = β_fp + 2 + m · (1 + ℓ_BF),      m = max_i m_i（不足处补 0）
```

### 1.4 BFF 编码

设 `k = k_BFF`（三位置），`L_BFF = R · C`。

```
映射：每个 K_i 分配到 k 个位置  u_{i,0}, …, u_{i,k−1} ∈ [0, L_BFF)
编码：D[u] ∈ Z_t^{B_pay}，满足重构恒等式
```

**BFF 核心等式**（对每个关键字、每个字段）：

```
D[u_{i,0}] − Σ_{a=1}^{k−1} D[u_{i,a}]  =  payload_i        (mod t)
```

等价地，**k 路相加即还原**：

```
Σ_{a=0}^{k−1} D[u_{i,a}]  =  payload_i                    (mod t)
```

> **实现方式（已验证）**：对前 `k−1` 个位置取随机份额，最后一个位置取差额：
> ```
> D[u_{i,k−1}] = payload_i − Σ_{a<k−1} D[u_{i,a}]
> ```
> 这与论文的 peeling 编码在**正确性上等价**（都满足上面的恒等式）。

**构成一维数组** `D : [0, L_BFF) → Z_t^{B_pay}`。

### 1.5 二维布局

```
u = r·C + c        （行列映射，全局统一；等价写法 u = c·R + r 亦可，但须一致）
D_2d[r][c] = D[u],   r ∈ [0,R), c ∈ [0,C)
```

### 1.6 明文多项式的构造（**pack each column**）

对**每个字段 `b`** 和**每一列 `c`** 各构造**一条**明文多项式：

```
P_{c,b}(X) = Σ_{r=0}^{R−1} D_2d[r][c][b] · X^r   ∈ R_t
```

**服务器状态**：

```
st_S = { P_{c,b}(X) : c ∈ [0,C), b ∈ [0,B_pay) }      ← 全部【明文】
```

**规模**：`C × B_pay` 条多项式，每条最多 `R` 个非零系数。

> ⚠️ **两条硬约束**：
> - `R ≤ N`（一条多项式只有 `N` 个系数，要装下 `R` 行）
> - 若实现走槽位打包（把一条密文的 `N` 个槽当 `N` 个位置），则收紧为 `R·B_pay ≤ N`
>
> ⚠️ **注意不要混淆**：`B_pay` 变大只意味着**多项式条数多**（`C×B_pay` 条），
> **不是**"二维放不下"。逻辑布局 `R×C` 与 `N` 无关。

### 1.7 评估材料

```
重线性化密钥 : rlk  = RLWE_{s_R}( s_R² )
自举密钥     : BK[j] = RGSW_{s_R}( s_L[j] ),   j ∈ [0,d)
```

> `BK` 的两种口径（见 §4.3）：按**秘密位**轮需 `d` 个；按**索引位**轮只需 `⌈log₂ N⌉` 个。

## 二、QUERY（客户端）

设查询是**合取查询** `K = (K_1, …, K_Q)`，取 `K_1` 为锚。

### 2.1 计算锚关键字的 BFF 位置

```
对 a = 0..k−1:
    u_a = h_a(K_1)              ∈ [0, L_BFF)
    r_a = u_a mod R             （行索引）
    c_a = ⌊u_a / R⌋             （列索引）
```

### 2.2 列选择器（**一个整体 RLWE 密文，系数承载 one-hot**）

```
对 a = 0..k−1:
    构造 one-hot 向量：e_a ∈ {0,1}^C,  e_a[c_a] = 1，其余 0
    把整个向量编进多项式的系数：
        e_a(X) = Σ_{c=0}^{C−1} e_a[c] · X^c  =  X^{c_a}
    整体加密成【一个】RLWE 密文：
        q_a^col ← RLWE_{s_R}( e_a(X) )
```

**要点**：
- 是 **一个** RLWE 密文，**不是** `C` 个独立密文
- 编码是**系数编码**：one-hot 的每一位是明文多项式的**一个系数**
- 索引由**系数位置**承载（不是由标量的值承载），所以一个密文就能表达整个 one-hot
- 轮转密钥形态：`q_a^col[c] = RGSW_{s_R}(e_a[c])` 时可直接参与 §3.7 的二进制内积

> ❌ **我先前的一个误解（已更正）**：曾写成"C 个独立密文，各加密一个标量"。
> 数学上二者是**同一线性泛函的两种表示**（见 §2.2.1），但整体多项式形态
> **通信量少 `C` 倍**、且**不升相位级**，是论文采用的形态。

#### 2.2.1 三种等价形态（数学上都成立）

| 形态 | 客户端密文数 | 相位级 | 备注 |
|---|---|---|---|
| **A. 整体多项式（论文）** | **1** | `Δ` | one-hot 编进系数，索引由位置承载 |
| B. `C` 个独立标量 | `C` | `Δ²` | 每个只加密 1 个比特，需 rescale |
| C. 槽位掩码 | 1 | `Δ²` | 需数据库也槽位编码 |

三者给出的明文多项式**相同**（都是 `P_{c_a,b}(X)`），差别只在通信量与相位级。

#### 2.2.2 服务端如何使用 `q_a^col`（**把系数当 LWE 样本**）

这是本方案的关键机制。对每个 `c`：

```
从 q_a^col 中"读出"第 c 个系数的 LWE 样本：
    Acc_c ← CtExtract_0( CtRotate(q_a^col, −c) )
    （把第 c 个系数转到常数位，再取常数项 —— 与 SampleExtract 同一思路）
```

其相位为

```
φ(Acc_c) = e_a[c] ∈ {0,1}
```

因为 `q_a^col` 的相位多项式正是 `e_a(X) = Σ_c e_a[c]·X^c`，
它的第 `c` 个系数就是 `e_a[c]`；旋转 `X^{−c}` 把它移到常数位后，常数项即该值。
**已实测确认**：`c = 0,1,2,3` 分别读出 `e[c] = 0,0,1,0`（`c_a = 2`）。

然后与对应列相乘并求和：

```
Acc_{a,b} ← Σ_{c=0}^{C−1} Acc_c · P_{c,b}(X)
```

由 `e_a` 的 one-hot 性质，只有 `c = c_a` 一项非零：

```
Acc_{a,b} 的明文 = P_{c_a,b}(X)          ← 恰好选中第 c_a 列
```

> ⚠️ **一个必须处理的实现细节（密钥变化）**
>
> 抽出第 `c` 个系数的 LWE 样本，其密钥是 `s_R` 的某个**循环移位**，**不是** `s_R` 本身
> （这正是 `LweRlweBridge.sampleExtract` 里那个 `d = j − k` 下标的来源）。
> 因此不能直接把它当作"与原累加器同密钥的密文"去乘明文多项式 ——
> 要变回与累加器同密钥的形态，需要**一次密钥切换**，或把结果 **Pack** 回去。
>
> **这正是论文 ANSWER 里 `SampleExtract` 与 `Pack` 成对出现的原因**：
> `SampleExtract` 把多项式"拆"成 LWE，`Pack` 再把它"合"回 RLWE。
>
> **实现上更省的做法**：若选择子以 **RGSW** 形态给出（`q_a^col[c] = RGSW(e_a[c])`），
> 则可用**二进制同态内积**（§3.7 的 `CtCtMul` + 折叠）直接在槽位域完成
> `Σ_c e_a[c]·P_{c,b}`，天然避免逐系数抽取与密钥切换。

### 2.3 行选择器（加密的整数）

```
q_a^row ← LWE_{s_L}( r_a )
```

实现层两种等价形态：
- **一条 LWE 密文** `(a, β)`，`a ∈ Z_{q_L}^d`，`β = ⟨a, s_L⟩ + r_a mod q_L`
- **逐位 RGSW** `{RGSW(r_a[j])}`（供 §3.3 的 CMUX 使用）

> ⚠️ **为什么行选择不能合并进列选择器**（我曾错误地认为可以）
>
> 列选择是**乘法**：用选择子去乘数据库，得到"某一列"。
> 行选择是**抽取**：要的是"第 `r_a` 个系数"，而不是"整条多项式乘个东西"。
>
> 若客户端把 `X^{r_a}` 加密后乘上去，得到的只是 `P(X)·X^{r_a}` —— **整条多项式被平移**；
> 客户端拿到后仍然无法私下取出第 `r_a` 个系数（它只拿到密文）。
> 抽取必须用盲旋转（或 `SampleExtract` + `Pack`），**这与乘一个单项式是两种不同的运算**。
> 所以两者的编码形态不同（列 = 系数位置；行 = 标量值），**不能合并**。
### 2.4 加密的 Bloom 查询向量

```
B_qry = Σ_{i=2}^{Q} B(K_i)          （除锚外每个关键词的位；客户端本地算）
τ     = ‖B_qry‖₁                     （阈值）
q_BF  ← SlotEnc_{s_R}( B_qry )       ← 槽位编码（这是唯一用槽位的地方）
```

**匹配判据**：

```
值 v 命中  ⟺  ⟨B_qry, b_v⟩ = τ
```

因为 `B_qry` 的每一位都要求被 `b_v` 覆盖，故

```
⟨B_qry, b_v⟩ ≤ τ,   等号 ⟺ 全部覆盖
```

> 这是单边判据 —— 只会**假阳性**（Bloom 固有），**不会假阴性**。

### 2.5 发送

```
q = ( { q_a^col }_a,  { q_a^row }_a,  q_BF )        ← 每个 a 只有【一个】q_a^col
```

## 三、ANSWER（服务器）

服务器只持有 `st_S`（明文）、`rlk`、`BK` 和 `q`。
**它不知道 `r_a`、`c_a`，也不知道 `K_1`。**

### 3.1 外层循环

```
对 a = 0..k−1:            （k 条 BFF 路径）
  对 b = 0..B_pay−1:      （每个字段）
```

### 3.2 步骤 A：列选择（`CtPtMul`，密文 × 明文）

```
Acc_{a,b} ← Σ_{c=0}^{C−1} Acc_c · P_{c,b}(X)      （Acc_c = CtExtract_0(CtRotate(q_a^col, −c))）
```

**为什么成立**：Acc_c 加密的是 e_a[c]（从 q_a^col 抽出的第 c 个系数），
`CtPtMul` 得到 `Enc(e_a[c] · P_{c,b}(X))`。取和：

```
φ(Acc_{a,b}) = Σ_c e_a[c] · P_{c,b}(X) = P_{c_a,b}(X)
```

即**恰好选中第 `c_a` 列的明文多项式**。

> ⚠️ 实现注意：`e_a[c] = 0` 的项**不要真的去做"乘 0"** —— 某些库会因结果是
> 透明密文（零明文）而报错。语义上零分量本就不贡献，**直接跳过**即可。

### 3.3 步骤 B：盲旋转选行

目标：把 `P_{c_a,b}(X)` 旋转 `X^{−r_a}`，使第 `r_a` 个系数落到常数项。

`r_a = Σ_{j} r_a[j]·2^j`，于是

```
X^{−r_a} = Π_j X^{−r_a[j]·2^j}
```

**逐位 CMUX**（`BK[j] = RGSW(r_a[j])`）：

```
cur ← Acc_{a,b}
对 j = 0..d−1:
    rot   ← CtRotate(cur, −2^j)                     （乘 X^{−2^j}，公开）
    cur   ← CMUX( BK[j], cur, rot )
        := cur + RGSW( r_a[j] ) ⊗ (rot − cur)
        （r_a[j] = 0 → 得 cur；= 1 → 得 rot）
Acc'_{a,b} ← cur
```

**性质**：

```
φ(Acc'_{a,b}) = X^{−r_a} · P_{c_a,b}(X)
```

**常数项的取值**（负循环规则）：设 `e = (−r_a) mod 2N`，则

```
系数 P_{c_a,b}[e mod N]        若 e < N
−P_{c_a,b}[e − N]              若 e ≥ N
```

> ⚠️ 常见误解：常数项**不是** `P[r_a]`，而是 `±P[(−r_a) mod N]`（负号来自 `X^N = −1`）。
> 若要直接得到 `P[r_a]`，须把旋转量写成 `X^{N−r_a}` 或让累加器初值带 `X^{+r_a}`。

### 3.4 步骤 C：SampleExtract（提取常数项）

```
ct_{a,b} ← CtExtract_0( Acc'_{a,b} )
```

**密钥变化**：`Acc'` 是 `s_R` 下的 RLWE；取常数项后得到 `s_L` 下的 LWE。

原因：`φ(Acc') = c_0 + c_1·s_R` 的**常数项**为

```
c_0[0] + Σ_{k} c_1[k] · (X^k·s_R 的常数项)
```

而 `s_R` 的第 `j` 个系数就是 `s_L[j]`，所以结果形如
`b − ⟨a, s_L⟩` —— 一个标准 LWE 密文。

**输出**：

```
ct_{a,b} = LWE_{s_L}( D_2d[r_a][c_a][b] )
```

### 3.5 步骤 D：k 路 BFF 相加（还原 payload）

```
对 b = 0..B_pay−1:
    ct_{pay,b} ← Σ_{a=0}^{k−1} ct_{a,b}
```

由 §1.4 的重构恒等式：

```
φ(ct_{pay,b}) = Σ_a D_2d[r_a][c_a][b] = payload_{K_1}[b]
```

即

```
ct_{pay,b} = LWE_{s_L}( payload_{K_1}[b] )
```

### 3.6 步骤 E：Pack（LWE → 槽位域 RLWE）

> **这是槽位第一次出现的地方。**

输入 `B_pay` 条 LWE 密文，输出 RLWE 密文，使各字段落在**不同槽位**。

设 `ct_i = (a^{(i)}, b^{(i)})`，`SwK[j][k] = RLWE(B^k · s_L[j])`。构造

```
ct_out ← Σ_i Σ_j Σ_k d^{(i)}_{j,k} · SwK[j][k]  +  (明文常数 b^{(i)})
```

其中 `d^{(i)}_{j,k}` 是 `a^{(i)}_j` 的 `B` 进制平衡位分解：

```
a^{(i)}_j = Σ_k d^{(i)}_{j,k} · B^k,     |d^{(i)}_{j,k}| ≤ B/2
```

**效果**：把各 `a^{(i)}_j·s_L[j]` 项转成 `s_R` 域，使相位只由 **LWE 相位**
（而不是 `a` 本身）贡献 → 得到**纯常数**相位：

```
φ = b^{(i)} − ⟨a^{(i)}, s_L⟩ = payload_{K_1}[i]
```

再用**槽位选择子** `E_i`（槽 `i` 为 1、其余 0）把它落到第 `i` 个槽：

```
ct_packed ← Σ_i ( 该常数密文 ⊗ E_i )
```

于是每个槽 `i` 存着 `payload_{K_1}[i]`。

**结果**：

```
ct_packed = SlotEnc_{s_R}( payload_{K_1} )        ← 槽位编码
```

### 3.7 步骤 F：Bloom 打分（二进制同态内积）

**必须在槽位域**：

```
ct_prod  ← CtCtMul( q_BF, ct_packed )            ← 逐槽相乘 = 按位 AND
ct_score ← ct_prod
对 r = 0 .. log₂ℓ_BF − 1:
    ct_score ← CtAdd( ct_score, CtRotate(ct_score, 2^r) )   ← 槽位折叠求和
```

**效果**：折叠把全部槽加起来，于是**每个槽**都等于

```
φ(ct_score) = Σ_i B_qry[i] · b_v[i] = ⟨B_qry, b_v⟩
```

**判据**（客户端）：

```
⟨B_qry, b_v⟩ = τ   ⟹  值 v 命中合取查询
```

### 3.8 响应组装

```
resp = ( ct_packed , ct_score )
```

## 四、DECODE（由前三步推出，此处只列其位置）

由 SETUP/QUERY/ANSWER 已完全确定：

```
1. 解密 ct_packed  → 得到 payload_{K_1}
2. 解析字段：
     指纹        ← 字段 [0, β_fp)
     值的个数 m  ← 字段 [β_fp, β_fp+2)
     第 j 个值    ← 字段 β_fp+2+(j−1)(1+ℓ_BF)
     其 Bloom     ← 后续 ℓ_BF 个字段
3. 指纹校验：与客户端本地算的 fp(K_1) 比对，不符则返回 ⊥
4. BFF 重构：k 个字段分量相加 mod t（已在 §3.5 于密文内完成，此处只是解读）
5. 阈值判定：⟨B_qry, b_v⟩ = τ ⟹ 该值入选
6. 输出结果集 V = { v : 判定命中 }
```

## 五、正确性条件（实现时必须检查）

| # | 条件 | 说明 |
|---|---|---|
| C1 | `X^N+1` 在 `F_t` 上完全分裂 | 否则槽位编码不成立 |
| C2 | `2N \| q−1` | 存在 `2N` 阶单位根 |
| C3 | `R ≤ N`（或槽位打包下 `R·B_pay ≤ N`） | 多项式容量 |
| C4 | `ℓ_BF ≤ N` | 一个 Bloom 要装进一条槽位密文 |
| C5 | `C ≤ N` | `C` 元 one-hot / 选择子要能放下 |
| C6 | `B^ℓ ≥ q` | 位分解能完整覆盖模数 |
| C7 | 明文（**含卷积系数**）`≤ ⌊(q/2)/Δ⌋` | 超出会翻到负半轴 |
| C8 | 重线性化需 **≥2 个工作素数** | 单素数上下文不支持密钥切换 |
| C9 | `d = LWE 维数 ≤ N` | `s_R` 按 `s_L` 铺开 |

## 七、实现顺序建议（逐步可验证）

每一步都有独立的验收判据，建议按此顺序落地：

| 步 | 内容 | 验收判据 |
|---|---|---|
| 1 | 参数与环 | `X^N = −1`；`X^N+1` 完全分裂；`Δ` 可逆 |
| 2 | 槽位编解码 | `toCoeff(toSlots(f)) = f`；逐点乘 = 环乘后转槽 |
| 3 | RLWE 加解密 | 往返；同态加/减 |
| 4 | `CtPtMul` + `CtRotate` | 相位线性变换正确 |
| 5 | `CtCtMul` + 重线性化 | 相位 = 两输入相位之积；缩放正确 |
| 6 | RGSW + 外部积 + CMUX | `RGSW(0)⊗c = 0`；`RGSW(1)⊗c = c`；CMUX 两分支 |
| 7 | **盲旋转** | `φ = X^{−r}·P`（整条多项式对拍） |
| 8 | SampleExtract | LWE 相位 = RLWE 相位常数项 |
| 9 | Setup（§1.1–1.6） | `Σ_a D[u_{i,a}] = payload_i` |
| 10 | 列选择（§3.2） | 选出 `P_{c_a,b}` |
| 11 | Answer 骨干（§3.1–3.5） | `ct_{pay,b} = LWE(payload[b])` |
| 12 | Pack（§3.6） | 打包结果直喂打分得到正确内积 |
| 13 | Bloom 打分（§3.7） | 命中得 `τ`；漏 1 位得 `τ−1` |
| 14 | Decode（§4） | 命中返回正确值集，不命中返回 ⊥ |

## 八、一句话总纲

> **数据库明文（`P_{c,b}`，系数编码）→ 加密查询（列选择子 = C 个独立标量密文，
> 系数编码；行选择子 = LWE）→ 列选择 `CtPtMul` 求和 → 盲旋转选行 →
> SampleExtract → k 路相加 → Pack 进槽位 → 槽位域 `CtCtMul` + 折叠得 Bloom 内积。**
>
> **槽位编码只在 Pack 之后出现。列选择阶段没有槽位参与。**
