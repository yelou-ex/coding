# 更正：列选择 —— 数据库明文 + C 个独立标量密文

> 起因：《列选择.md》指出我在描述列选择时有两处错误。**两处都确认是我错了**，已改正并验证。
> 日期：2026-10-02

---

## 一、我错在哪（两处）

### 错误 1：我把数据库多项式**加密**了

我之前的表述是"服务器存储 `ct_{c,b} = RLWE_{s_R}(P_{c,b}(X))`"。

**这是错的。CAPE 是 PIR,不是 FHE 数据库。**

| | FHE 数据库 | **CAPE（PIR）** |
|---|---|---|
| 数据库 | 加密 | **明文** |
| 服务器在什么上计算 | 密文 | 明文 + 加密的**查询** |
| 保护谁 | 数据 | **查询隐私**（服务器不知道你查什么） |

服务器本来就**拥有**数据库,数据库不需要对它保密。

```
D[0..L_BFF−1]                         ← 明文
D_2d[r][c]                            ← 明文
P_{c,b}(X) = Σ_r D_2d[r][c][b]·X^r    ← 明文多项式，服务器直接存
```

### 错误 2：列选择子我用的是**槽位编码**

我说过"把整个 one-hot 向量用槽位编码装进一条 RLWE 密文"。**这是错的。**

**正确做法：列选择子是 C 个独立密文,每个只加密一个标量 0/1,且是系数编码（常数多项式）。**

论文 Algorithm 1：

```
Acc_{a,b} ← Σ_{c=0}^{C−1} CtPtMul(q_a^col[c], P_{c,b}(X))
```

- `P_{c,b}(X)` 是**明文多项式**
- `q_a^col[c]` 是**加密的标量**（0 或 1）
- `CtPtMul` = **密文 × 明文**

**为什么不能是槽位编码**：服务器要算 `Σ_c e_a[c]·P_{c,b}(X)`,这里 `c` 是**列索引**。
若选择子是槽位编码,解密后在**槽位 i** 上有值 —— 槽位与列不对应,加权求和无法成立。

## 二、实测验证（`CapeColumnSelectionFixed`）

**N=2048、C=4、B_pay=20、R 行**

```
--- 1. SETUP（全明文）---
    P_{c,b}(X) 共 C×B_pay = 4×20 = 80 条【明文】多项式
    ⚠️ 全程不调用 encrypt —— CAPE 是 PIR，数据库不加密

--- 2. QUERY（客户端）---
    目标条目 (r_a, c_a) = (7, 2)，两者都保密
    q^col = 4 个【独立】密文，各加密一个标量（21 ms）
            第 2 个是 Enc(1)，其余是 Enc(0)
    q^row = LWE 加密的行索引（服务器看不到 r_a）

--- 3. ANSWER ---
    CtPtMul 决策 80 次（C=4 列 × B_pay=20 字段）
    其中真正做乘法 20 次（只有 c_a 那列参与）
    耗时 1018 ms

--- 4. 验收 ---
    [PASS] 4.1 取到的 payload == D[r_a][c_a][·]（20 个字段全对）
    [PASS] 4.2 负对照：换一列（其选择子 = Enc(0)）→ 结果不同
```

**链路**：列选择（`CtPtMul` 求和）→ **盲旋转**（把第 `r_a` 个系数移到常数项）→ 读常数项。
两步合起来正确取到 `D[r_a][c_a][b]`。

## 三、修正对照表

| 项 | ❌ 我之前 | ✅ 修正后 |
|---|---|---|
| 数据库 `P_{c,b}(X)` | RLWE 加密 | **明文** |
| 列选择子 `q^col` | 一个槽位 one-hot 密文 | **C 个独立密文,各加密一个标量** |
| 列选择子编码 | 槽位编码 | **系数编码（常数多项式）** |
| `CtPtMul` 含义 | 密文 × 明文多项式 | 同左 |
| 槽位何时出现 | 列选择阶段 | **Pack 之后**（做 Bloom 内积时） |

**"槽位在哪里出现"的正确图景**：

```
FusePIR 检索（系数编码，无槽位）
  数据库明文多项式 + 加密查询（系数编码）
  → 列选择 CtPtMul → 盲旋转 → SampleExtract → LWE 密文

Pack（槽位第一次出现）
  把 B_pay 个 LWE 密文打包成 RLWE 密文
  → 输出槽位编码

CAPE 过滤（槽位编码）
  q_BF（槽位编码）× ct_j^BF（槽位编码）
  CtCtMul 逐槽相乘 + CtRotate/CtCtAdd 折叠 = 内积
```

## 六、一句话总结

> **CAPE 是 PIR：数据库明文,只有查询加密。**
> 列选择子是 **C 个独立密文,每个加密一个标量 0/1（系数编码）**,
> 服务端做 `Σ_c CtPtMul(q^col[c], P_{c,b}(X))` 选出目标列,再盲旋转选行。
> **槽位编码要到 Pack 之后才出现**,与列选择阶段无关。
