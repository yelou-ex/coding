# 索引噪声：结论与依据（含负面结果）

> 日期：2026-10-16
> **结论：靠"调还原式"解决不了，缺的是 `BitDecomp` 的舍入测试多项式。**

---

## 一、论文依据（§2.3，L363）

```
LWE：b = ⟨a, s⟩ + Δ·m + e     (mod q)
     "Δ is a scaling factor determined by the plaintext encoding."
     "Correct decryption recovers m as long as the accumulated error
      remains below the decoding bound."
```

**我们的实现用的是 Δ = 1**：

```java
BlindRotateOps.lweEncryptIndex:   beta = floorMod(sum + r, qL)   // 没有 Δ
```

---

## 二、为什么"调还原式"修不好（结构性原因）

### 2.1 `BlindRotate` 的代数

```
CMUX 循环产出 = X^{⟨a,s⟩} · P
末尾旋转      = mulX(cur, −β)
总效果        = X^{⟨a,s⟩ − β} · P
```

**要取到 `P[r]`，必须 `⟨a,s⟩ − β ≡ −r`，即 `β ≡ ⟨a,s⟩ + r`。**
这就是为什么 Δ=1 时 `β = ⟨a,s⟩ + r + e` 能工作（e=0 时），且**噪声直接进指数**。

### 2.2 加 Δ 之后为什么不成立

若 `β = ⟨a,s⟩ + Δ·r + e`：

| 做法 | 总效果 | 结果 |
|---|---|---|
| 末尾 `mulX(cur, −β)` | `X^{−Δ·r−e}·P` | ❌ 指数含 `Δ·r`，落不到位置 |
| 先算 `r̂ = round(β/Δ)` 再 `mulX(cur, −r̂·Δ)` | `X^{⟨a,s⟩ − Δ·r̂}·P` | ❌ 仍含 `⟨a,s⟩` |

**根本困难**：服务端**无法把 `β` 拆成 `⟨a,s⟩` 与 `Δ·r` 两部分** —— 它不知道 `⟨a,s⟩`。
所以"从带噪相位里精确恢复整数索引"这一步，`BlindRotate` 的末尾旋转**做不到**。

> 论文那句 *"recovers m as long as the accumulated error remains below the
> decoding bound"* 里的**"解码"是 LWE 层的一步操作**，不是旋转本身。

## 三、真正缺的环节：`BitDecomp` 的舍入测试多项式

论文 §2.5 说：

> *"RGSW ciphertexts are used **internally by blind rotation** and explicitly by
> the query-compressed variants for selector expansion."*

标准 CGGI 盲旋转里，把带噪 LWE 变成精确比特靠的是**舍入测试多项式**：

```
用测试多项式 T(X) = Σ_{i=(q/4−ε)}^{(q/4+ε)} X^i  （或类似形式）
做一次"取模切换 / 舍入"的盲旋转，把相位夹到 0 或 q/2 附近
→ 得到精确比特
```

**这与我们撞到的另一处坑是同一个环节**：

| 坑 | 位置 | 状态 |
|---|---|---|
| `LweToRgswOps` 的比特提取多项式不对 | lou 标记 **4/4 失败** | 未解决 |
| **索引噪声零容忍** | README §3.4，本文 | 未解决 |

**⇒ 两个坑收敛到同一个缺失的原语。** 修好 `BitDecomp`，两处一起解决。

## 四、本次实测（有量化价值）

### 4.1 符号/方向定死（`BlindRotateAlignProbe`）

```
CMUX 用 +a[i] + 末尾用 −β   →  常数位 = 100+r  ✓  ← 唯一正确组合
CMUX +a / 末尾 +β           →  0
CMUX −a / 末尾 −β           →  0
CMUX −a / 末尾 +β           →  0（r=0 时对，其余错）
```

### 4.2 当前实现（Δ=1）的噪声容限（100 组/档）

| σ | 命中率 |
|---|---|
| **0** | **100%** |
| 1 | 37% |
| 2 | 21% |
| 3 | 11% |
| 4 | 10% |
| 8 | 6% |
| 16 | 5% |

**论文参数 σ ≈ 1.79 → 命中率约 20–25%（不可用）。**

### 4.3 一个失败尝试：载荷重复 D 份

思路（README 候选 a）：每行占 D 个连续系数、值重复 D 份，
使"噪声 < D/2 时落回同一行"。

实测（**注：本实验的索引编码对齐有误，数据仅供参考**）：

| D | σ=1 | σ=2 |
|---|---|---|
| 1 | 41% | 18% |
| 2 | 63% | 39% |
| 4 | 69% | 52% |
| 8 | 75% | 58% |
| 16 | 74% | 61% |

**趋势改善但未达 100%，且平台化** —— 而且**候选 (a) 与论文 SETUP 第 14 行
`P_{c,b}(X) = Σ_r D[r+cR][b]·X^r`（一行一个系数）冲突**，需先确认论文是否真的这么做。

## 五、结论

| 项 | 结论 |
|---|---|
| 端到端四步流程 | ✅ 结构与代数正确（**前提：索引无噪声**） |
| 真实噪声下的端到端 | ❌ **未达成**，且**不是调参能解决** |
| 缺的原语 | **`BitDecomp` 的舍入测试多项式**（把带噪 LWE → 精确比特） |
| 与另一处坑的关系 | `LweToRgswOps` 4/4 失败**同源** |
| 论文原文是否已读全 | ⚠️ §2.5 的原语定义段**已读**（`BlindRotate`/`SampleExtract`/`Pack`/`LWEtoRGSW`），但**舍入测试多项式的具体形式论文未给**（属标准 CGGI 细节） |
