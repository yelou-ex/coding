## 一、要做什么（论文依据）

```
A1 QUERY 5: q^row_a = LWE.Enc_{s_L}(r_a)      <-- 真 LWE 密文，**必然带噪声**
§2.5      : LWE.Enc 里 b = <a,s> + Δ·m + e
```

现状是 `b = ⟨a,s⟩ + r_a`（`Δ=1, e=0`）—— 即偏差 **D1**。要补的就是那个 `e`。

## 二、机制：噪声**不是污染**，而是"整体平移取数位置"

盲旋转的常数系数**就是** `P[phase]`（`nativeCapeAnswer` 末尾的
`multiply_power_of_x(cur, −β)`）。所以

```
b = ⟨a,s⟩ + m + e   ⇒   phase = m + e   ⇒   取到 P[m + e]，**不是 P[m]**
```

这一条 `BlindRotateStress` 早就实测过（`e=256` 就整体推 256 格，且 `got` 严丝合缝等于 `p[r+e]`）。
⇒ **「加噪声」要成立，必须让 `P` 的取数位置有余量。**

## 四、⭐ 量纲分析（本轮真正的产出）

### 4.1 判据：真正的设计量是 `Δ/√d`，不是 `Δ`

```
容差          = Δ/2                     （块宽的一半，纯坐标事实）
累积噪声      ≈ 3σ√d                    （d 个独立误差之和，3σ 界）
通过          ⟺  Δ/2 > 3σ√d
             ⟺  **Δ / √d > 6σ**         ← 设计量
```

### 4.2 ⚠️ 瓶颈：`Δ` 的上限是 `N/R`，而 **`R` 论文没给**

块不能折回负循环，所以 `Δ·R ≤ N` ⇒ `Δ ≤ N/R`。
把 4.1 与它合起来：

```
6σ√d < Δ ≤ N/R        ⇒        R < N / (6σ√d)
```

取论文常用 `σ = 3.2`：

| | d=16 | d=512（论文） |
|---|---|---|
| 需要 `Δ >` | 77 | **434** |
| `N=4096` 时 `R ≤` | 53 | **9** |
| `N=8192` 时 `R ≤` | 106 | **18** |
| `N=16384` 时 `R ≤` | 213 | **37** |

**而 `R` 是什么**：`A1 SETUP` 第 836–837 行 `r_a = u_a mod R` —— **`R` 就是行数**，
也就是"布局里每个槽位能容纳的行数"。它由数据规模（每个关键词最多几个值）与
`RC ≥ L_BFF` 一起定出，**论文只在 SETUP 第 4 行说 `Select R,C such that RC ≥ L_BFF, R ≤ N`，
没有给具体值**。

> **⇒ 这条是本轮最硬的发现：把行选择子改成带噪之后，"R 能不能压到 18（N=8192）/ 37（N=16384）"
> 变成了一个必须先回答的问题。** 而它此前从未出现在任何文档里 —— 因为
> `Δ=1` 时 `R ≤ N` 这条约束**宽到不可能被触发**，噪声把 `R` 的有效上限从 `N` 压到了 `N/Δ`，
> 也就是**压小了约 434 倍**。

### 4.3 临界 `d`（本实现这一组参数下）

`N=8192`、`R=16` ⇒ `Δ` 上限 `= 512` ⇒ 临界 `d ≈ (512/(6·3.2))² ≈ 711`。
论文是 `d = 512 < 711` ⇒ **在我们这组参数下本项可行**，但余量只有 1.4 倍。

## 五、为什么**主动停止**（不是"不会做"）

1. **知识部分已经拿到**：上面 §四 整段就是这项的全部结论，而且它**不需要**跑代码 ——
   量纲分析用纸笔就能验证（我确实用独立脚本复核过）。
2. **工程部分我连崩两次**，且都是**我自己**的问题：
   * 第一版探针把 `C=26 / B_pay=59` 全带上跑 —— **一轮几分钟**，
     而且把"块宽吸收能力"与"LWE 噪声累积"两个**互相独立**的误差源混在了一起，
     结论会被与 `d` 无关的东西污染；
   * 改小规模之后又发现：`Δ` 这一侧**可以**缩规模（它是纯坐标事实，与 `C/B_pay/d` 严格无关），
     但 `R ≤ N/Δ` 那一侧**不能**缩 —— 必须按真实 `N/R` 算。
   * 这两条教训本身有价值，已写进本文 §六。
3. **收益对比**：继续磨下去，最好的结果是"把 §四 的结论变成可跑断言"。
   但 §四 的结论**已经是可独立复核的数学**，而这条路上还有 `R` 这个**论文没给、
   需要我们自己定**的自由参数 —— 也就是说**即使跑通了，也还需要一个设计决定**，
   不是纯实现工作。

**⇒ 结论：本项应记为「分析与判据已完成，实现待定，且待定的前提是先定 `R`」。**

## 六、方法论：两个误差源必须分开测（这条对以后所有噪声类任务都适用）

| # | 来源 | 依赖 | 能不能缩规模测 |
|---|---|---|---|
| ① | 块宽 `Δ` 对平移 `e` 的吸收能力 | 只依赖 `Δ` 与 `e`；**与 `C`、`B_pay`、`d` 严格无关** | ✅ **能**（缩了严格无损，是纯坐标事实） |
| ② | LWE 噪声的累积 | 依赖 `d` 与 `σ`；与 `C`、`B_pay` 无关 | ✅ 能（在 `d` 上扫，不用动别的） |
| ③ | **容量**约束 `Δ·R ≤ N` | 依赖 `N` 与 `R` | ❌ **不能** —— 必须按真实值算 |

**⇒ 正确的降规模方式是"换旋钮"**：不要缩 `N`（它会同时动 ① 的可行域和 ③ 的边界），
而是**在固定 `N` 上缩 `C`/`B_pay` 测 ①，单独扫 `d` 测 ②，③ 只用公式**。

> 反面教训（就是本项第一版）：缩 `N` 会让 ① 的结论看起来成立或失败，
> 但那与 ② 的规模纠缠在一起，**得不出可用于论文参数的结论**。
