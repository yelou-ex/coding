        ((Get-ChildItem "$root\lib\deps" -Filter *.jar | ForEach-Object { $_.FullName }) -join ';')

New-Item -ItemType Directory -Force -Path $out | Out-Null

$routeC = @('RgswOps.java','RgswCiphertext.java','MonomialOps.java','BootstrapKey.java',
            'RgswLabMain.java','MonomialKeyTest.java','LabConfig.java')
$src  = @()
$src += (Get-ChildItem "$root\rgsw-lab\src\main\java\com\fusepir\rgsw" -Filter *.java |
         Where-Object { $_.Name -notin $routeC } | Select-Object -ExpandProperty FullName)

         Select-Object -ExpandProperty FullName)          # ← 新增:必须带上

**`LweRlweConversion`（LWE↔RLWE 互转自检）**
```
[PASS] T0 取 RLWE 私钥的系数形式（LWE-in-RLWE）
[PASS] T1 RLWE → LWE：解出的向量与 cape.he 密钥 = 原密文对应系数
[PASS] T2 单路径 LWE 密钥桥（CAPE 的密钥切换路径）
[PASS] T3 LWE → RLWE：Pack 回第 j 个系数后 RLWE 解密 = 原值
[PASS] T4 q_L = 2N 装配进 t=65537（Δ = q/t = 0）**的文档化写法**
```

> T4 这个测试名很关键：`q_L = 2N = 4096` 而 `t = 65537`，所以 `Δ = q_L/t = 0`。
> 也就是说**LWE 层不能靠"缩放"承载明文** —— 这正是为什么盲旋转里 `a_i` 直接当旋转指数用。
> 他们把这条"文档化"并加了测试。

**`BlindRotateStress` — 维度扫描(d=64→512)**
```
d= 64 | 密钥   317 ms | 盲旋转   240 ms | 常数位 got=235 want=235 OK | 整条 2048/2048
d=128 | 密钥   378 ms | 盲旋转   347 ms | 常数位 got=235 want=235 OK | 整条 2048/2048
d=256 | 密钥   821 ms | 盲旋转   708 ms | 常数位 got=235 want=235 OK | 整条 2048/2048
d=512 | 密钥  1609 ms | 盲旋转  1375 ms | 常数位 got=235 want=235 OK | 整条 2048/2048
→ d 到 512 全部正确，累加器整条一个系数都没错
```

**`BlindRotateStress` — 噪声扫描(d=512,相位 = ⟨a,s⟩ + r + e)**

这一项最有信息量。**实测结论：盲旋转对输入噪声是"精确抵消"的** ——
`e = ±1/±2/±4/…/±256` 时,常数位 `= p[r+e]`,即**噪声"干净地"把旋转量偏移 e 格**,
而**不是污染结果**。这正是 CGGI 自举应有的行为。

| e | 常数位 | p[r] | p[r+e] | 判定 |
|---|---|---|---|---|
| 0 | 235 | 235 | 235 | = p[r] ✅ |
| 1 | 236 | 235 | 236 | = p[r+e]（偏移 1 格） |
| 3 | 238 | 235 | 238 | = p[r+e] |
| 8 | 243 | 235 | 243 | = p[r+e] |
| 256 | 491 | 235 | 491 | = p[r+e] |
| −1 | 234 | 235 | 234 | = p[r+e] |
| −4 | 231 | 235 | 231 | = p[r+e] |

**为什么这很重要**：自举的容错原理就是"小噪声只造成可控偏移,舍入后仍能恢复"。
如果噪声是"污染"(结果变成随机值),方案就不可用。他们专门测了这个性质。
