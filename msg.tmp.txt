fix(route-A): RGSW gadget 构造修正 —— RGSW(1) 乘 ct 已 0/4096 错位

根因（本轮定位到并修掉）：RGSW 的 gadget 常数必须直接加进相位，不是当消息加密。
- 错：g0[i] = Enc(g_i*mu mod t) —— 相位是 Delta*g_i*mu，多了个 Delta = q/t 因子
- 对：g0[i] = Enc(0)，然后把完整的 g_i = base^i 加到分量 0 的常数项（相位 += g_i*mu）
      g1[i] = Enc(0)，把同样的 g_i 加到分量 1（相位额外带出 s）
这正是 Java 侧 addConstantNtt 的语义；而且 gadget 要用完整 base^i（base^4 = 2^64 超 uint64，
所以用 __int128 累加），不是 base^i mod t。

结果：RGSW(1) 乘 ct = ct 0/4096 错位，噪声预算 51 bit —— C++ 侧的
切段 / CRT / 点乘密集累加 / 形态约定全部验证正确。
